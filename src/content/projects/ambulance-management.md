## Overview

A full-stack web application built on the **MERN stack** (MongoDB, Express.js, React, Node.js). I led the UI, server
and database integration.

## What I did

- Built a **course-navigation guide** for IIT Jodhpur students.
- Developed an **ambulance dispatch system** with JWT-based user authentication and a dedicated client–server
  architecture with **priority-based dispatch queuing**. It was adopted by multiple medical facilities.
- Designed the **MongoDB Atlas** schema and custom queries for fast access to patient data.
